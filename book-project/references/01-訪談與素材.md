# 01 訪談與素材管理

書的素材有兩種：**作者自己的記憶**（最珍貴、也最容易記錯）與**別人的記憶**（需要授權）。這一節處理「怎麼問、怎麼記、怎麼標狀態」。

## 一、作者深度訪談

### 節奏
- 每次 30–60 分鐘，**一次一個主題**，不要想一口氣問完所有題目。
- 開場先說明用途、時間、會不會錄音、可以隨時叫停；這不只是禮貌，而是讓回答品質變好的條件。
- 結束前問一句：「今天有沒有哪一段你不想被寫進去？」——先問，比事後爭議便宜太多。

### 必問主題（第一次見面就能問）
1. 一個最鮮明的家族／職場／主題現場畫面（盡量問到氣味、聲音、天氣、誰站在哪裡）。
2. 一次明顯感受到「正在失去或改變」的時刻。
3. 一項已經消失或改變的食物、分工、儀式、流程。
4. 一位把大家牽在一起的人（他做了什麼、怎麼說話）。
5. 你希望下一代／讀者記得的那件事。
6. 你希望讀者讀完**立刻**做的那一件事。

### 追問技巧
- 抽象→具體：把「很辛苦」追成「那天幾點起床、誰先去、做了什麼」。
- 時間軸化：把「以前」追成「哪一年、你幾歲、誰還在」。
- 對照化：「那時候跟現在最大的差別是什麼？」
- 允許空白：「這段你希望完全不談，還是只記到某個範圍？」

## 二、受訪者自行錄音（非常有用的一招）

面對晚輩或訪問者容易緊張的長輩／受訪者，可以**先把題目交出去，請他自己錄音**。

流程：
1. 說明用途（我在做什麼、這段會用在哪裡）。
2. 給題目清單（一次 8–12 題為宜）。
3. 對方自己挑時間錄，遇到沒印象、不想答的題目**直接跳過**。
4. 訪問者再約一次 15–20 分鐘補訪，只問追問與過場。
5. 逐字稿整理後，**交本人校訂**，再確認引用範圍。

誠實原則：若受訪者先錄回答、訪問者後來補錄提問，**不能剪接成彷彿兩人同步對談**的現場。文稿要標明「受訪者自述」與「補訪問答」，或由作者說明資料形成方式。

## 三、逐字稿

- 方言（台語、客語等）語音轉文字（ASR）**人名、地名、寺名、稱謂幾乎不可信**，且常分不清「夫家／娘家」一類的歸屬。ASR 稿只當線索。
- 事實一律請**本人校訂**；校訂版優先於任何 ASR 判讀。
- 校訂時常見的更正類型：人名、地名、專有名詞、親屬歸屬、年代、先後順序。
- 整理成稿時保留原意，修掉贅詞可以，**不可以替受訪者增加沒說過的因果與情緒**。
- 逐字稿、錄音、照片都放在受控位置，不進 repo；repo 只記代碼、狀態與位置。

## 四、素材台帳（每個專案都該有的核心檔案）

這是「素材 ↔ 章節 ↔ 授權」的唯一真相來源。每一項素材至少八欄：

| 欄位 | 說明 | 常見錯誤 |
|---|---|---|
| 素材編號 | `FI-001`（訪談）、`PH-001`（照片）、`AU-001`（錄音）、`DO-001`（文件）、`OB-001`（物件）、`EX-001`（外部案例） | 沒有編號，日後無法回查 |
| 來源人物／來源 | 作者、家人、讀者、專家、公開資料 | 只寫「聽來的」 |
| 日期與地點 | 不確定寫「約〇〇年代」，**不猜** | 用想像的年代讓敘述變順 |
| 可用章節 | 對應一章或多章 | 沒有對應，素材最後沒用 |
| 事實狀態 | 已確認／待確認／不同說法並存 | 把單一說法寫成「全家都認為」 |
| 授權狀態 | 未詢問／僅供參考／可匿名引用／可具名引用／不可使用 | 口頭聊天就當成出版授權 |
| 匿名需求 | 真名／化名／關係模糊化／完全匿名 | 只換名字，其他線索仍可辨認 |
| 原始檔位置 | 受控位置代碼（**不寫公開連結**） | 把雲端連結寫進 repo |

台帳另外附一張 **「章節資料缺口對照表」**：每章列出「還缺什麼素材」與狀態（待補／部分補入／作者確認無此經驗）。有這張表，就不會發生「以為每章都完成了，其實都在等同一批資料」。

狀態誠實很重要：作者明確說「我們家沒有這種經驗」時，就把狀態寫成「作者家族無此經驗；如需案例須另尋其他家庭並取得授權」，**不要因此改成編一個**。

## 五、授權與匿名

### 同意至少分四層（每一層都要另外確認）
1. **願意談**：此刻願意回答這個主題。
2. **願意記錄**：同意錄音、錄影或筆記。
3. **願意保存與分享**：知道資料放哪裡、哪些人能看。
4. **願意公開或出版**：清楚媒介、範圍與可能讀者。

「都是自己人」「他沒反對」都不等於同意。原先只說家族內部整理、後來想放進書裡，**必須重新取得同意**。

### 訪談前先讲清楚「怎麼退出」
約定簡單的停止訊號（直接說「先停一下」「這段不要記」、手勢暫停錄音、把某題標成之後再談、要求刪除剛才的段落、整場結束不必說明理由）。受訪者用了停止訊號之後，**不能被追問、說服或責怪**。

### 家人生理訊號
不是每個人都會直接拒絕。突然長時間沉默、反覆轉移話題、呼吸急促、握緊雙手、眼神失焦、語氣變得防衛、一再問「你要拿這個做什麼」——都值得停下來問：「要不要休息？這題可以不回答。錄音要先關掉嗎？」

### 保存方式可以分級
不記錄／本人保存／家族限定／延後開放（約定日期或當事人離世後再確認）／匿名使用／公開出版。

匿名不是只把姓名換掉：地點＋職業＋親屬關係＋特殊事件的組合，仍可能讓熟人辨認。若無法安全匿名，**寧可不用**。

### 案例授權書建議欄位
受訪者與訪問者與日期、訪談目的與使用媒介、錄音／錄影／照片／文字的使用範圍、是否具名或化名、可否節錄編輯翻譯（不得改變原意）、校稿與更正方式、撤回或縮小授權的聯絡方式與時間界線、涉及第三人的處理原則、保存地點與期間與可接觸者、雙方簽名或可證明的電子紀錄。正式文件仍應由出版或法律專業者確認。

## 六、敏感議題

需要特別謹慎的主題：收養、身世、非婚生子女、失聯、失蹤、夭折、流產、喪親、戰爭、政治事件、災害、暴力、貧困、債務、失業、財產爭議、婚姻衝突、離婚、外遇、家暴、疾病與身心狀況、性生活、犯罪紀錄、宗教轉換、家族決裂。

原則：
- 不要因為要寫家族史，就預設每一項都必須問。
- 只有受訪者理解目的、願意談、且內容與主題有關時才繼續。
- 訪問者不扮演治療者；出現強烈情緒時先回到當下（水、陪伴、選擇）。
- 矛盾說法並列記錄，標明「誰在什麼時候提供」，不寫成「全家都認為」；涉及指控的內容不能只憑單一口述公開。
- 和解不是訪談必須達成的成果；不要用「都是一家人」要求受傷的人原諒，也不要把敏感錄音播給其他親屬對質。
