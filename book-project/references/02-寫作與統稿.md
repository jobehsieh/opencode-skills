# 02 寫作與統稿

## 一、章節企劃卡＝寫作合約

每章開寫之前，先把這八格寫定（沒寫定就不要開始寫正文）：

1. **章節任務**：這一章要替讀者解決什麼（一句話）。
2. **開場故事**：用哪個場景開場，來源是作者經驗／授權案例／綜合示例。
3. **核心觀點**：讀者讀完要帶走的那一句。
4. **內容範圍**：寫什麼、**明確不寫什麼**（避免越寫越細、離題）。
5. **案例或代表素材**：素材編號，或明確標示「待補」。
6. **一項主要工具**：表格、清單、腳本、檢核表（**一章一個就好**）。
7. **讀者「今晚就能做」的行動**：具體到今晚可以完成的動作。
8. **待補素材與專業審讀需求**：列出缺口與要找哪一類專業者。

全書節奏建議固定：**家庭場景 → 讀者痛點 → 文化／關係解釋 → 方法與案例 → 本章行動**。固定節奏的好處是讀者不用每章重新適應，作者也不必每章重新發明結構。

## 二、單章九步

1. 讀章節企劃卡。
2. 盤點現有真實素材與資料缺口。
3. 決定開場性質：作者故事／授權案例／**明確標示的**綜合示例。
4. 寫「場景—痛點—解釋—方法—行動」初稿。
5. 檢查有沒有把推測寫成事實。
6. 加入一項工具或「今晚就能做」的行動。
7. 檔首註明初稿限制與待確認內容。
8. 更新素材台帳的缺口清單。
9. 作者確認聲音、事實、界線與願不願意公開。

## 三、開場的性質一定要標示

在檔首「初稿說明」寫清楚：這是作者真實經驗、還是綜合示例、還是尚待授權的案例。例如：

> 初稿說明：依章節企劃撰寫，開場為常見情境，**並非作者家族的特定事件**；作者已確認內容方向。

> 初稿說明：開場為綜合示例，不影射特定成員；「〇〇」一節已補入作者家族的真實做法（經本人校訂並同意匿名使用）。

這一行看起來瑣碎，但它決定日後編輯、法務、作者本人能不能信任這份稿子。**示例被誤讀成作者親身經歷，是這類書最嚴重的事故。**

## 四、統稿與去重

### 1. 先做「主場章節」對照表
同一個故事、場景或論點，只在**一個章節完整敘述**（主場），其他章節縮成一句並指向主場。

| 主題 | 主場 | 其他章節處理 |
|---|---|---|
| 例：某個家族場景 | 第四章（完整） | 序章保留一個畫面；其他章一句話帶過 |

先建這張表再逐章改，比「一章一章潤飾」有效得多——因為重複是**跨章**的問題，逐章看永遠看不出來。

### 2. 年代與格式統一
- 全書採同一種年代寫法（例如「西元為主、括號民國」）。
- 學術引用的出版年屬書目格式，不動。
- 檔名或表格若受格式限制，可在正文另註。

### 3. 語氣與人稱
- 自述型非虛構：全書統一第一人稱（我／我們家）；初稿說明與清單可保留「作者」。
- 他人的話：轉述或直接引語要一致；直接引語需本人確認文字。
- 刪重複用語：同一個形容詞在一章出現五次就該減。

### 4. 統稿順序（按風險與依賴，不按章號）
補真實素材 → 取得授權 → 事實查核 → 工具實測 → 專業審讀 → 全書統稿 → 敏感度閱讀 → 作者終審。

### 5. 作者逐章口述補訪的實務
當某一章需要「作者經驗」時，最有效率的方式是**逐章問、逐章寫**：
1. 先讀該章，列出「需要作者提供的具體事實」清單（一次 3–5 題，不要 10 題）。
2. 問完立刻寫入，並把新增內容放進該章最合適的位置（通常不是開場，而是論點段落）。
3. 同步更新檔首說明與章末缺口清單，並在素材台帳記錄「哪一章用了哪一項素材」。

實例：一章談「邀請家人為什麼會讓人不舒服」，若作者回答「我們家現在每個月都有家聚餐會」，這段真實經驗最適合放在「相聚寧可小而完整」那一節，而不是取代開場的示例——因為開場需要張力，而作者的經驗是解答，不是問題。

## 五、敏感度閱讀（全書統稿後做一次）

- 性別：家務與照顧是否只由女性承擔的描述？有沒有把性別分工寫成理所當然？
- 信仰：非宗教者、不同宗教者的位置有沒有被寫進去？有沒有暗示只有某種做法才有效？
- 收養／身世／不孕／單親／同志家庭：是否預設了「標準家庭」？
- 失落與創傷：是否要求讀者「一定要和解」「一定要走出來」？
- 族群與地域：地方習俗有沒有被寫成全體通則？用語是否尊重當地人對自己的稱呼？
- 經濟與階級：是否暗示「有心就一定做得到」？

## 六、品質檢查表

### 每章交稿前
- [ ] 開場故事的來源清楚。
- [ ] 綜合示例沒有被寫成作者親身經歷。
- [ ] 人名、地名、年代、親屬關係已確認或標示待查。
- [ ] 地方習俗沒有被擴大為唯一做法。
- [ ] 不以恐懼、孝不孝或神效迫使讀者接受觀點。
- [ ] 不同信仰、性別、世代與無宗教者有被尊重。
- [ ] 敏感內容遵守自願揭露原則。
- [ ] 案例、照片、錄音、機構資訊的授權狀態清楚。
- [ ] 本章只有一個主要工具或行動。
- [ ] 與前後章沒有大量重複。

### 全書送出前
- [ ] 企劃、目錄、章號、章名、雙向連結一致。
- [ ] 核心方法（書的骨架，例如四個關鍵字）在全書各部分都有落點。
- [ ] 作者真實故事與工具型內容比例平衡。
- [ ] 所有引用、數據與專業說法可追溯原始來源。
- [ ] 可辨識的家人資訊已取得同意或妥善匿名。
- [ ] 作者逐章確認個人聲音與公開界線。
- [ ] 外部專業審讀意見已記錄採納或不採納的理由。

## 七、常見失誤（都是真實踩過的）

| 失誤 | 症狀 | 解法 |
|---|---|---|
| 太早開始寫 | 目錄漂亮但每章都在等同一批素材 | 先訪談，再企劃，再寫 |
| 按章號順序寫 | 卡在沒素材的第一章，全書停擺 | 先寫素材最成熟的章節 |
| 用想像填缺口 | 細節很順但作者說「我沒這樣說」 | 缺口標示，不編造 |
| 示例被當真 | 讀者以為是作者家族故事 | 檔首明確標示性質 |
| 重複敘述 | 同一個場景在四章出現 | 先建主場對照表 |
| 單一家庭當通則 | 「台灣人都這樣拜」 | 寫明地區、族群、年代，並請專業者確認 |
| 一章塞三個工具 | 讀者不知道要做哪一個 | 一章一個主要行動 |
| 只潤飾不補素材 | 文字變漂亮，可信度沒變 | 依風險順序（素材 → 授權 → 查核 → 統稿） |
